## 🚀 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rugvednikam/digimarkly-website.git
   cd digimarkly-website
   ```

2. **Run a local development server**:
   Using Python:
   ```bash
   python -m http.server 3000
   ```
   Or using Node / npx:
   ```bash
   npx serve .
   ```

3. **Open in browser**:
   Navigate to `http://localhost:3000/` or `http://localhost:3000/index.html`.
